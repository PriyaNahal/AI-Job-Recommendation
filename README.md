# AI-Job-Recommendation
AI-Powered Job Recommendation System

This project is about an AI-powered job recommendation system. Traditional job recommendation systems can be less accurate as they use keyword matching and can’t understand semantic similarity between words. A job recommendation system that uses AI can help with this as it can understand semantic meaning and can recommend the right jobs even if the terminology is different. The objective of this project is to have users upload their resume and extract the text, job titles, and skills from it. Then these are used to gather jobs from different APIs and get the semantic similarity scores. This is further improved by using an overall similarity score which takes into consideration the semantic similarity, job titles, and skills. Users will receive their scores and missing skills analysis for each job posting.
